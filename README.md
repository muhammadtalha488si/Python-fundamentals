# Basic Python Fundamentals

This repository contains my beginner-level Python practice. I used small examples and programming questions to revise fundamental Python concepts, built-in data structures, loops, and introductory Object-Oriented Programming (OOP).

The exercises are kept together in `python.py`. Most examples are currently commented out, so they are available for reading and revision but will not run until uncommented. The countdown generator at the end of the file is executable.

## Topics Practiced

### 1. Python Fundamentals
- Taking user input with `input()`
- Converting input with `int()`
- Displaying output with `print()`
- Arithmetic, comparison, and logical operators
- Modulus operator (`%`)
- Conditional statements: `if`, `elif`, and `else`
- Checking odd/even numbers, finding the greatest of three numbers, and checking multiples of 7

### 2. Lists
- Creating lists
- Indexing and slicing
- Adding elements with `append()` and `insert()`
- Sorting with `sort()`
- Reversing with `reverse()`
- Removing elements with `remove()` and `pop()`
- Copying lists with `copy()`
- Finding a list's length with `len()`
- Practice problems involving favourite movies, palindrome checking, and sorting grades

### 3. Tuples
- Creating tuples
- Indexing and slicing
- Checking a value's type with `type()`
- Finding an element's index with `index()`
- Counting occurrences with `count()`

### 4. Dictionaries
- Creating dictionaries
- Working with nested dictionaries
- Accessing values using keys
- Getting keys with `keys()`
- Getting values with `values()`
- Getting key-value pairs with `items()`
- Safe lookup with `get()`
- Updating dictionaries with `update()`

### 5. Sets
- Creating sets and working with unique elements
- Adding and removing elements
- Clearing a set with `clear()`
- Removing an arbitrary element with `pop()`
- Combining sets with `union()`
- Finding common elements with `intersection()`

### 6. Loops and Iteration
- `while` loops and `for` loops
- The `range()` function
- Iterating through lists and tuples
- Searching for an element
- Using `break` and `continue`
- Using a loop's `else` clause
- Printing number sequences and multiplication tables
- Calculating the sum of the first N numbers
- Calculating a factorial

### 7. Object-Oriented Programming (OOP)
- Defining classes and creating objects
- Constructors with `__init__()`
- The `self` parameter
- Instance attributes and methods
- A basic car-start example labelled as abstraction
- An account example with debit, credit, and balance methods
- Inheritance
- Static methods with `@staticmethod`
- Calling a parent-class constructor with `super()`
- An employee/engineer example introduced under polymorphism

### 8. Generators
- Generator functions
- The `yield` keyword
- Iterating over generated values
- A simple countdown generator

## Example Practice Questions

- Check whether a number is odd or even.
- Find the greatest of three numbers.
- Check whether a number is a multiple of 7.
- Store favourite movie names in a list.
- Check whether a list is a palindrome.
- Count how many times a grade appears in a tuple.
- Sort a list of grades.
- Search for a number in a tuple using a loop.
- Calculate the sum of the first N numbers.
- Calculate a factorial.
- Create `Student`, `Car`, `Account`, and `Employee` classes.
- Generate a countdown using `yield`.
